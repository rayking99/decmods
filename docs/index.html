Native decision heads and local model runtimes. Published timing includes all calls needed for a decision. Model precision and prompt layouts differ; warmup and loading are excluded.

Every replay comes from a saved trace. Human play uses browser game engines and a deterministic baseline. It is separate from the measured model results.

Experiment notes & limitations +

Loading the captured experiment method…

Latency and policy agreement address different questions. A one-step rule can disagree with stronger long-term play. Small seeded game runs are illustrations, not a statistically reliable tournament. Browser playback cadence is unrelated to measured inference latency.

Clef Flash 9B · MLX 4-bit uses its native joint decision head. Its encoder sorts choice IDs internally. Request order can still change tournament groups and break exact maximum-probability ties: the native answer builder chooses the first tied action in the request. These game benchmarks use text descriptions; image and video performance is outside this experiment.

Cache behavior and runtime adapters are recorded with the data. Consult the raw artifacts before comparing models or repeating the experiment.

BlockStar source & adaptation +

BlockStar is an open puzzle project by rayking99. This experiment adapts its game rules for explicit legal-action model decisions; the adaptation is documented in the captured source record.
