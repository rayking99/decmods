A shared API, with native engines underneath

Ollaya’s TypeSafe-compatible API covers Winnow, Laya, Kev and CLM. Its Mac acceleration differs by family. This experiment also exposes a single local /v1/systemone gateway on port 11440, routing explicitly to Ollaya or the authors’ Python runtimes.

Laya English uses an expanded 8k token budget to preserve the complete inputs; its default is 512. Multilingual Laya officially supports this longer context. Julia uses strict encoding with an MPS batch-placement adapter checked against its CPU reference. CLM uses a Python Hugging Face last-token embedding adapter with its original projection heads; repeated embedding cache hits are reported separately. Lev uses its native engine with an explicit MPS device-placement adapter. Jev-Omni’s native loader currently requires CUDA.
