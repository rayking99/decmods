How this experiment works +

The engine simulates each legal landing and supplies holes, heights, surface roughness, and rows cleared. The selected model chooses an action through a local /v1/systemone endpoint.

Above 26 landings, it picks winners from two shuffled groups, then chooses between them. No moves are discarded by a heuristic. Grouping can affect the result.

The replay includes model metadata, complete API requests and responses, move latency, and the board after every move. These models were trained for decisions and classification; this is an experiment in game decisions.
